# 财富之门 玩法档案

1. 名称：财富之门
2. 类型：原创转轴电子游戏
3. 主界面：独立主题背景与6×3图标网格
4. 逻辑画面：900×680，等比适配
5. 转轴：6
6. 每轴图标：3
7. 图标：金 / 银 / 铜 / 玉 / 红 / 蓝 / 紫 / 钥
   8–13. 机制、中奖、Wild、Scatter与奖励：原创演示规则：6×3外向内三组镜像双轴；每组对应的三行全部相同或有钥匙Wild7才开门；第1/2/3门奖励4/8/12倍积分；三门全开总基础奖励三倍；至少两门再加随机1–9倍积分。
8. 动画：独立runes装饰，逐轴停止，中奖高亮，结果阶段过渡
9. 音效：独立配置的合成旋律及启动/停止/中奖音
10. 流程：登录、选择消耗、服务器结算、客户端演示、历史记录
11. 帮助：运行页可读本文件对应的规则说明
12. 手机：等比画布与触摸按钮
