# 太阳神殿 玩法档案

1. 名称：太阳神殿
2. 类型：原创转轴电子游戏
3. 主界面：独立主题背景与5×5图标网格
4. 逻辑画面：900×680，等比适配
5. 转轴：5
6. 每轴图标：5
7. 图标：霞 / 云 / 焰 / 光 / 日 / 金 / 阳
   8–13. 机制、中奖、Wild、Scatter与奖励：原创演示规则：5×5以中央图标为光源；内圈8格同色至少3枚、外圈16格至少5枚分别计奖；奖励=积分×(中心序号+1)×(同色数−门槛+1)×圈半径；两圈全部同色时总奖励三倍。
8. 动画：独立runes装饰，逐轴停止，中奖高亮，结果阶段过渡
9. 音效：独立配置的合成旋律及启动/停止/中奖音
