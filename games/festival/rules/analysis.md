# 节日狂欢 玩法档案

1. 名称：节日狂欢
2. 类型：原创转轴电子游戏
3. 主界面：独立主题背景与5×3图标网格
4. 逻辑画面：900×680，等比适配
5. 转轴：5
6. 每轴图标：3
7. 图标：灯 / 鼓 / 花 / 礼 / 星 / 焰 / 乐 / 彩
   8–13. 机制、中奖、Wild、Scatter与奖励：原创演示规则：5×3至少三枚彩纸7进入庆典模式，仅边框普通同色四枚起奖=积分×(图标序号+1)×(数量−3)×2；否则只检查中间一行完整五连，奖励=积分×(图标序号+1)×5。
8. 动画：独立orbit装饰，逐轴停止，中奖高亮，结果阶段过渡
9. 音效：独立配置的合成旋律及启动/停止/中奖音
10. 流程：登录、选择消耗、服务器结算、客户端演示、历史记录
11. 帮助：运行页可读本文件对应的规则说明
12. 手机：等比画布与触摸按钮
13. 已确认：本项目全部原创演示规则及源代码；免费揭示如有均在同一付费局内合并结算，不再扣分、不无限重触发
