# 龙之传说 玩法档案

1. 名称：龙之传说
2. 类型：原创转轴电子游戏
3. 主界面：独立主题背景与5×4图标网格
4. 逻辑画面：900×680，等比适配
5. 转轴：5
6. 每轴图标：4
7. 图标：珠 / 角 / 云 / 火 / 金 / 玉 / 鳞 / 龙
   8–13. 机制、中奖、Wild、Scatter与奖励：原创演示规则：5×4原始某列有至少两龙7时，下一列全变Wild7，不连续传播新产生的Wild；从左连续三列起评估1024路；普通图标0–6独立计奖=向下取整(积分×路数×(图标序号+1)×(连续列数−2)/8)。
8. 动画：独立wave装饰，逐轴停止，中奖高亮，结果阶段过渡
9. 音效：独立配置的合成旋律及启动/停止/中奖音
10. 流程：登录、选择消耗、服务器结算、客户端演示、历史记录
11. 帮助：运行页可读本文件对应的规则说明
12. 手机：等比画布与触摸按钮
13. 已确认：本项目全部原创演示规则及源代码；免费揭示如有均在同一付费局内合并结算，不再扣分、不无限重触发
