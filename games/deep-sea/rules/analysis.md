# 深海秘境 玩法档案

1. 名称：深海秘境
2. 类型：原创转轴电子游戏
3. 主界面：独立主题背景与4×6图标网格
4. 逻辑画面：900×680，等比适配
5. 转轴：4
6. 每轴图标：6
7. 图标：贝 / 珊 / 鱼 / 珠 / 藻 / 潮 / 蓝 / 泡
   8–13. 机制、中奖、Wild、Scatter与奖励：原创演示规则：4×6各列向上循环移1/2/3/4格；变换后每行从左同色连续三枚起奖=积分×(图标序号+1)×(长度−2)；初盘气泡7至少五枚，连线奖励二倍并另加积分×气泡数。
8. 动画：独立embers装饰，逐轴停止，中奖高亮，结果阶段过渡
9. 音效：独立配置的合成旋律及启动/停止/中奖音
10. 流程：登录、选择消耗、服务器结算、客户端演示、历史记录
11. 帮助：运行页可读本文件对应的规则说明
12. 手机：等比画布与触摸按钮
