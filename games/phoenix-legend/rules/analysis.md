# 凤凰传奇 玩法档案

1. 名称：凤凰传奇
2. 类型：老虎机电子游戏；原创演示
3. 主界面：独立主题 Canvas 场景
4. 比例：浏览器自适应，900×680逻辑尺寸
5. 转轴数量：6
6. 每轴图标：5
   7–8. 图标与功能：见 game-engine/rules.ts 与 PhaserRenderer.ts；原版待确认
   9–10. 组合与计算：原创 6×5 集群：五枚正交相邻同色消除，连消倍率递增，最多五轮。
7. 特殊图标：无
8. 免费游戏：未实现，不声称原版有或没有
9. 奖励：仅虚拟积分，服务端计算
10. 动画：转轴、停止、中奖高亮、金币及集群过渡
11. 音效：Web Audio合成音，主题音阶独立；无录制原版音乐
12. 流程：登录→选积分→服务端结果与记账→前端动画
13. 帮助：运行页规则弹窗
14. 手机：Canvas等比缩放，44px按钮
15. 已确认：本项目原创规则，不代表授权游戏
16. 待确认：全部原版界面、素材、赔付、Wild/Scatter、免费游戏、RTP、音效及交互
