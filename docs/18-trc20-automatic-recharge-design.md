# TRC20 自动与人工审核设计（默认关闭，配置后启用）

最新需求：用户输入基础金额，系统分配两位小数应付金额；同时保留人工审核和链上自动审核。已确认：应付10.37 USDT即增加10.37分，现有积分和不可变流水保留原整数意义，新增整数小数位字段。使用公共TRONGrid并保留可选服务端API Key；默认关闭充值，由所有者配置真实地址及二维码后启用。

## 交易核验

TRON主网USDT合约固定为TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t，不按token symbol判断。V1账户TRC20记录只用作交易发现；每笔必须通过/walletsolidity的交易体、执行回执和固化区块再次核验。解析实际USDT合约Transfer日志，核对收款地址、微USDT整数金额、交易执行成功、固化状态、订单时间范围。使用交易哈希+日志序号作为全局唯一事件键。

积分变动、订单完成、链上事件绑定和审计必须在同一D1事务内完成；人工和自动审批使用同一结算入口。查询重放、Worker重试和并发审核不能重复加分。

## 两位小数的分配

候选应付金额使用整数微USDT表示，禁止浮点比较。固定地址仅靠两位小数可能发生迟到付款误配：相同金额如果分配给新订单，旧用户迟到付款会无法区分。因此同一收款地址的精确应付金额不重复分配；取消、过期和完成后也不释放该金额。某基础金额的100个尾数耗尽后停止分配，要求选择其他基础金额或由管理员更换地址，不能盲目重复尾数。

若未来需要无限重复报价，应使用每单独立收款地址或经过验证的发送方绑定，而不是降低上述保护。订单保存地址和二维码快照，收款设置更改不改写历史订单。

## 运维边界

Cloudflare Workers Cron可按分钟扫描；页面可按5秒轮询订单状态。不能将其宣传为零延迟到账。RPC超时、429、分页遗漏、链上未固化或核验不一致时保持待确认并重试，不猜测成功。迟到付款进入人工复核。

不需要钱包私钥、助记词或签名权限。TRONGrid Key只保存在服务端Secret，前端不得获取。当前没有真实收款地址、二维码或主网实付验收结果，不宣称链上自动入账已完成。

## 启用与验收

所有者进入 `/admin/recharge`：填写真实TRON收款地址，上传二维码，自行扫码核对，勾选开放充值。只需人工审核时保持自动审批关闭；需要自动匹配时再勾选自动审批。用户通过 `/recharge` 创建订单；每个用户最多5笔待处理订单。历史订单保留收款地址和二维码快照，相关二维码禁止删除。

公共接口每次请求至少间隔600ms，每笔交易最终通过固化接口核验。每轮最多核验6笔新交易、审批4笔订单，每分钟轮转一个收款地址；交易缓存及回执日志采用批量SQL，控制免费套餐的单次查询额度；429及查询失败后至少退避120秒。较大积压或公共接口限流会增加到账等待时间，可提交交易哈希主动核验。系统扫描最近24小时创建的未结订单；更早或迟到的付款交由人工通过交易哈希复核，不会丢弃账目。

自动及人工审核均要求精确应付金额的链上凭证。金额不符或缺少固化凭证不能点击批准绕过。驳回需填原因；已批准及已驳回订单不可改写。不会发送链上交易或支持提现。

`0005_fractional_points.sql` 为钱包、流水新增整数小数位，保留历史整数列；游戏整数消耗和奖励不改变小数余额。D1触发器把订单批准、一次性事件绑定、钱包积分、积分流水、审计及通知放入同一原子操作。部署前记录D1 Time Travel恢复书签到私有审计记录，不导出用户数据到公开仓库或素材桶。

可选的Cloudflare构建Secret `AURUM_TRONGRID_API_KEY` 会映射为Worker运行时Secret `TRONGRID_API_KEY`。未配置时直接使用公共接口，前端只返回是否配置的布尔状态。
