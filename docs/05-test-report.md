## 修复过的实际问题

收藏请求会在整页跳转时被中断：增加请求保留和操作互斥。WebGL软件渲染造成计时拖慢：改用Canvas与原始时钟，降低目标帧率。注册测试曾误选Next路由播报器，已限定表单错误区域。页面初始会重复创建游戏：等待会员与目录加载完成，并将真实横幅ID传给场景。历史程序版本禁止伪标发布或运行当前程序冒充旧版。
