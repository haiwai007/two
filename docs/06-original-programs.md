# 0.2 原创程序扩展

30款名称均来自需求；本次为全部条目编写独立原创规则，不是授权原版参数复刻。各目录的rules/index.ts是实际服务端程序，config.ts、scenes/Main.ts与audio/config.ts分别包含主题布局、独立场景装饰及合成旋律。

不同玩法包括五线/243路/集群、中央Wild扩展、金字塔免费揭示、随机山路、行内军阵、罗盘航线、斜向森林群、纵向咒语、2×2方阵、全盘水果、横向融化、八向射线、锁定矿石重转、中心对称、雷霆整轴、双向边缘、连续栖地、边框庆典、模数密码锁、后继1024路、黄金重铸、同心光环、中央旋转、七点星图、潮汐错位、点数重复型、季节棋盘与镜像门。

公共引擎只共享网格、相邻组查找、连续段和场景播放；不同游戏的变换条件、判定拓扑、倍率和奖励流程在独立规则文件中。不能将任意一个函数换名称后代表其他游戏。

免费揭示和免费重转是有界的本局内奖励：不再扣积分，不递归触发，服务端一次计算全部阶段，在一条game_records和对应积分流水中合并原子结算。前端steps只负责展示。重试返回相同存储结果，规则版本写入gameVersion。

数据库升级：先应用0002账本保护迁移，再执行scripts/catalog-v02.sql。已有offline游戏保持下架，已有会员、余额、记录和收藏保留。新安装用更新后的seed.sql即可。scripts/seed-if-empty.mjs只对空目录初始化，避免重放seed导致误覆盖。

新增数据库保护：积分算术校验、游戏金额/整数范围校验、记录与账本不可更新/删除。运维备份或未来迁移不能靠直接修改旧账本修复，应使用补偿流水并保留审计。

运行控件：开始、最多10局自动运行、快速动画、跳过动画、音效、帮助、记录、全屏和退出。跳过只加速演示，不取消或修改已结算结果。网络不明时停止自动运行并保留用户专属请求ID，不能重复扣分。

所有授权原版的素材、界面、RTP及规则仍待正式资料；没有声称原创概率参数经过商业认证。生产上线还需Cloudflare账户连接、Turnstile实际配置和域名验收。

图标默认使用随程序打包的原创AI生成图标（public/symbols），不使用任何第三方厂商素材；可通过game.config.symbolAssets绑定R2素材覆盖，无需修改赔率或重写程序。夺宝免费旋转为共享原创机制，参考常见现代转轴游戏的Scatter/倍数递增思路，不复刻任何厂商规则。客户端退出后会忽略迟到的旧局回调，积分展示更新也绑定原会员ID，避免不同账号之间串用显示状态。

升级脚本只更新0.1版本，不反复覆盖0.2自定义介绍；下架状态保留，历史已发布程序标记archived，旧版本不伪装为当前版本运行。
